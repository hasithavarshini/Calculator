# Calculator
This project is a simple  Calculator built in Python.
It supports basic arithmetic operations (addition, subtraction, multiplication, and division), mathematical functions such as exponentiation, square root, factorial, logarithms, and trigonometric functions (sin, cos, tan). The calculator also displays the value of Pi and handles user-friendly error messages for invalid inputs. This is a console-based application aimed at providing a complete, user-friendly mathematical calculator for all types of users, including students, engineers, and scientists.
